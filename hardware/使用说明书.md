# 轮速监测台转接底板 使用说明书

适用硬件：v6 转接底板（96 × 98.5mm，含 C1 25V / R5 1.5k / D3 SB560 / C4 1000µF/16V）
日期：2026-10-28

> **先看这一条：** 4S 电池从 J12 端子直接进板时，板上的 +BEC 母线就是电池电压
> （满电 16.8V）。v6 已经让 **J7/J8 舵机固定吃板载 5V**、**J9 只走三路信号**，
> 这两类负载不怕 4S；但 **J17 的 +V 仍连 +BEC**，4S 模式下必须把接收机的 +V
> 电源线空出来，接收机改由电调 BEC 直接供电。霍尔 J3~J6 的 +V 也是 16.8V，
> A3144 标称 4.5~24V，可以接；J15 的 BEC 针在 4S 下同样是 16.8V，别拿它给
> 6V 设备供电。

---

## 1. 板子与接口

开发板（Freenove ESP32-S3 WROOM CAM）**正面朝上**插在 J1/J2 两个 20 针排母上：
J1 顶排对开发板右排（IO43 列），J2 底排对左排（3V3 列），天线朝左、USB 朝右。
外设接口的脚序不再统一：

- **舵机 J7/J8**：信号 / +5V / GND；
- **霍尔 J3~J6**：+V(BEC) / GND / 信号，对应 A3144 的 1=VCC、2=GND、3=OUT；
- **遥控 J9**：三针全是信号，1=模式、2=前差速、3=后差速，没有电源和地；
  接收机的电源和地走 J17。

| 接口 | 用途 | 说明 |
|---|---|---|
| J1 / J2 | 开发板排母 | J1=右排 IO43 列，J2=左排 3V3 列；针号 1 在远离 USB 口的一端，丝印有三角标 |
| J3~J6 | 霍尔传感器 ×4 | 左前 / 右前 / 左后 / 右后，A3144 一类开集电极霍尔；脚序 +V/G/S |
| J7 / J8 | 舵机 ×2 | 前差速 / 后差速；+V 固定为板载 5V |
| J9 | 接收机信号输入 | 一个 3 针排针：1=模式、2=前差速、3=后差速；只走信号 |
| J12 | 电源输入端子 | 1 脚 +，2 脚 GND；螺丝端子，适合粗线/大电流 |
| J13 / J14 | 扩展排针 | 与开发板 40 针 1:1 直连（J13=J1，J14=J2） |
| J15 | 电源条 2×8 | 上排从左到右：3V3×3、5V×3、BEC×2；下排全是 GND |
| J16 | 电调 3 针接口 | 信号 / +BEC / GND；电调 BEC 从这里进板 |
| J17 | 接收机油门接口 | 信号 / +BEC / GND；油门信号从 J16 直通过来，同时给接收机供电 |
| LED1 | +BEC 电源指示 | 绿灯亮 = 输入母线有电压 |
| LED6 | 5V 输出指示 | 绿灯亮 = LM2596 降压段有 5V 输出 |

J15 的 3V3 针由开发板上的 3.3V 稳压器供给，开发板没插时这 3 根针没有电；
5V 针由板上的 LM2596 供给；BEC 针就是输入母线的电压。

## 2. 供电方式与电压范围

板上有两个电源入口，**同一时间只能接一个**：

- **J16（电调 BEC 输入，推荐日常使用）**：电调 BEC 输出 6~7.4V 从这里进板。
  这时板上 +BEC 就是 6/7.4V；J7/J8 舵机仍走板载 5V，接收机可以接 J17 的 +V。
- **J12（螺丝端子，可接 4S）**：换上升级件后，可接 6~16.8V。
  4S 锂电满电 16.8V 是上限；不要接 5S 或更高。低到 6V 左右仍能工作，
  再低 5V 段会跟着掉，开发板和舵机都可能不稳。4S 直接进板时 J17 的 +V
  是 16.8V，接收机不能接（见第 3 节）。

**绝对不要同时接 J12 和 J16。** 如果把 4S 接到 J12，同时又把电调的三针插头
插在 J16，电调 BEC 的 6/7.4V 会和 4S 母线顶在一起，轻则保护、重则烧线。
如果这时还需要油门信号过板，只能给 J16 接**信号和地两根线**，把中间那根
+BEC 线拔掉/剪断；或者干脆不用 J16/J17 的直通。

输入范围（按 v6 的 C1 25V、R5 1.5k、D3 SB560、C4 1000µF/16V 配置）：

| 项目 | 数值 |
|---|---|
| 推荐输入 | 6~7.4V（电调 BEC），或 4S 电池 12~16.8V |
| 最高输入 | **16.8V（4S 满电）**，不要超过 |
| 最低输入 | 约 6V；低于 6V 时 5V 段进入压差区，开发板和舵机都不稳 |
| 5V 段 | LM2596 降压到 5.0V；6V 输入时约 4.9~5.1V 属正常；同时供开发板和两路舵机 |
| 反接保护 | D1（1N5824）可防反接，但不要故意试；反接时板子不工作 |

板面丝印仍写着「BEC 6~7.4V」，那是按电调 BEC 的标称输入印的；**4S 能力来自
C1/R5/D3/C4 这几个升级件，丝印没有逐项改**。以本说明书为准。

## 3. 4S 直接进板时的硬性注意事项

这是整份说明书最重要的部分。

### 3.1 板上 +BEC 会变成 16.8V

+BEC 母线上接着：

- J15 的两个 BEC 针；
- J17 接收机油门接口的 +V；
- J3~J6 霍尔接口的 +V；
- 板上的 5V 降压电路和电源指示灯。

v6 已经把 J7/J8 舵机改到板载 5V、把 J9 改成纯信号排针，所以舵机和遥控信号
不再直接吃 16.8V。4S 满电时仍要注意：

- 霍尔 A3144 标称 4.5~24V，16.8V 没问题，可以继续接。
- J17 的 +V 是 16.8V，接收机不能接；接收机由电调 BEC 单独供电。
- J15 的 BEC 针在 4S 模式下也是 16.8V，不要拿它给 6V 设备供电。
- 舵机 J7/J8 的 +V 是板载 5V，4S 下可以接；但 5V 降压段的电流/散热要按
  第 6 节核算，不要超过 LM2596 的能力。

### 3.2 接收机怎么接

接收机由电调 BEC（6/7.4V）直接供电，不经过板上的 +BEC：

- 接收机的电源正负极直接接电调 BEC 的输出（或独立的 6/7.4V BEC）；
- 接收机到板上的三路信号接 J9 的 1/2/3 脚（模式/前差速/后差速），J9 没有电源脚；
- 接收机的油门信号和地走 J17：J17 的 1 脚信号、3 脚地，**2 脚 +V 空着**；
- 接收机的地要和板子的地共地（同一块 4S 电池的负极），否则信号没有参考，
  可能读不到；
- 如果接收机完全不用，J9/J17 不接线即可。

注意：J9 没有地线，接收机的信号参考地是通过 J17 的 GND 建立的，所以 J17 必须
插上；只插 J9 不插 J17，三路信号没有参考地。

### 3.3 舵机怎么接

v6 的 J7/J8 +V 是板载 5V，4S 直接进板时舵机也可以接板上的 +V。要注意的是
5V 降压段的电流和散热：两路舵机堵转电流加起来可能接近或超过 LM2596 的 3A
上限，4S 输入时压差大、芯片发热也大。大舵机建议另配 5V BEC，不要全压在
板上这一路；第一次用 4S 带舵机时先短时间试，摸一下 U1 温度。

### 3.4 什么情况下可以用 J16 的 BEC 输入

如果你改用 J16（电调 BEC 6/7.4V）给板子供电，就回到正常模式：

- 这时板上 +BEC 是 6/7.4V；J7/J8 仍走板载 5V，接收机可以接 J17 的 +V；
- J12 必须断开，不能同时接；
- 如果接收机已经由电调 BEC 直接供电，J17 的 +V 可接可不接；两路是同一个
  电源节点，接上只是并联，不会升压。

## 4. 接线细节

- **舵机 J7/J8**：信号 / +5V / GND，和舵机标准插头一致；+V 是板载 5V。
- **霍尔 J3~J6**：+V(BEC) / GND / 信号，对应 A3144 的 1=VCC、2=GND、3=OUT；
  插之前对一下板上丝印的 +V / G / S。
- **遥控 J9**：三针全是信号，1=模式、2=前差速、3=后差速；没有电源和地。
  接收机的电源/地走 J17，J17 必须插上，否则这三路信号没有参考地。
- **J16 和 J17 的油门直通**：J16 的信号脚和 J17 的信号脚在板上是纯铜直连，
  板子不通电也照传信号；主控没上电不会断油门。J16 的 +BEC 是电源输入脚，
  4S 模式下必须空着（见 3.4）；J17 的 +V 在 4S 下也要空着（见 3.2）。
- **J12 极性**：1 脚 +，2 脚 GND，按端子旁边的 +/- 丝印接；接反了 D1 会挡，
  但不要依赖它，接线前先用万用表确认。
- **J15 电源条**：上排是电源、下排是地，每一列一对我；用两针杜邦壳插一列
  就能取电。上排从左到右依次是 3V3、3V3、3V3、5V、5V、5V、BEC、BEC。
- **开发板方向**：v6 是正面插装，J1 顶排对开发板右排（IO43 列），J2 底排对
  左排（3V3 列）；J1/J2 的 1 脚都在远离 USB 口的一端，装板前对一遍丝印和
  「正面插入 USB→」标注。J13/J14 与 J1/J2 一一对应，扩展排针上的网名已经
  逐针印好。
- 开发板插着 USB 调程序时，板上的 5V 和 USB 5V 之间有 D2 隔离，不会互相
  倒灌；但接线时还是建议先断电。

## 5. 首次上电检查

1. 先不插开发板、不接外设，目视检查：
   - C1、C3、C4 的极性（电解电容的负极/条纹）；
   - D1、D2、D3 的方向（D1 的色环/阴极标记朝电路侧）；
   - U1 的 1 脚方向、焊盘有没有连锡；
   - J12 的 + 和 GND 没有接反。
2. 用限流电源或 6V BEC 从 J12/J16 供电（二选一），先量：
   - +BEC 对 GND：应等于输入电压；
   - +5V 对 GND：应约 5.0V（6V 输入时 4.9~5.1V 正常）；
   - J7/J8 的 +V 对 GND：应为 5V（不是 BEC 电压）；
   - J17 的 2 脚对 GND：应为 +BEC；J3~J6 的 1 脚对 GND：应为 +BEC；
   - LED1、LED6 都应亮。
3. 确认 5V 正常后再插开发板，然后接霍尔、舵机、接收机。开发板是正面插装：
   J1 对右排（IO43 列），J2 对左排（3V3 列）。
4. 准备用 4S 时，第一次先不接接收机和舵机，只给板子和霍尔上电，确认 5V
   正常、U1 不烫，再接其他东西；接舵机后再摸一次 U1 温度。
5. 任何接线改动前先断开电源和电池。

## 6. 电流、散热与保护

- **D1（1N5824）**：5A 平均电流，是整板 +BEC 总电流的瓶颈；两路舵机现在
  通过 5V 降压段取电，输入电流也要过 D1，选线/保险丝时把这一路算进去。
- **J12 端子**：10A 级别；大电流（舵机）尽量走 J12 粗线，不要全从 2.54 排针过。
- **3 针排针/J15**：每针约 1~3A（按厂家），舵机堵转电流大时注意不要只走
  一根细针；J7/J8 的 +5V 和 GND 各只有一根针，大舵机要控制堵转时间。
- **5V 段**：现在同时供开发板和两路舵机，不再是小电流支路。LM2596 的 3A
  是芯片上限，实际连续电流要留余量；C4 1000µF 只能兜瞬时，不能替代余量。
- **LM2596 的散热**：输入从 7.4V 提到 16.8V 后，压差变大、耗散增加；
  5V 负载 1A 时，7.4V 输入约 2.4W，16.8V 输入约 11.8W，已经需要认真散热。
  长时间带舵机或车内高温环境建议给 U1 加 TO-220 散热片；大舵机建议另配
  5V BEC。
- **保护**：板上只有 D1 防反接，**没有保险丝、没有过压保护**。建议在电池
  和 J12 之间串一个 3~5A 保险丝；电池短路电流很大，别省这一步。

## 7. 4S 升级与 v6 器件变更

4S 输入要换的三个器件（v6 出厂已按这套配置）：

| 位号 | 原值 | 换成 | 说明 |
|---|---|---|---|
| C1 | 1000µF/16V | **1000µF/25V**（Ø10×20mm，5mm 脚距，105°C） | 4S 满电 16.8V 时约 67% 降额；16V 件会超压 |
| R5 | 1k 1/4W | **1.5k 1/4W** | 16.8V 时 1k 约 0.22W，贴近 1/4W 额定；1.5k 约 0.15W。6V 时指示灯会暗一点，能看出亮 |
| D3 | 1N5822（40V） | **SB560（60V/5A，DO-201AD）** | 16.8V 输入下续流二极管振铃余量更足；同封装 |

v6 还把 **C4 从 220µF/16V 升到 1000µF/16V**：两路舵机现在挂在 5V 上，
堵转时靠它兜瞬时电流。封装仍是 Ø10 / 5mm 脚距，原位替换。

不用换的：

- C3 220µF/25V：16.8V 时 67% 降额，够用；
- D1 1N5824：30V 反向耐压大于 4S，5A 电流不变；
- U1 LM2596T-5.0：工作到 40V，16.8V 在范围内；
- D2、C2、L1、接插件：都在 5V 侧或与电压无关。

**如果还是原装的 C1 16V / R5 1k / D3 1N5822，不要接 4S**，最高只能按
原来的 6~7.4V BEC 使用（C1 的 16V 耐压是硬限制）。

v6 的 PCB 因为正面插装、5V 舵机和遥控排针合并已经重排，不能把 v5 的
走线/接口顺序直接照搬；这一节只说明器件替换。已经打好的 v5 板子要接 4S，
直接换 C1/R5/D3（以及可选换 C4）即可，不需要重新打样。

## 8. 常见问题

| 现象 | 先查什么 |
|---|---|
| LED1 不亮 | 输入有没有电、J12 极性、保险丝、D1 方向 |
| LED1 亮、LED6 不亮 | 5V 段：U1 方向/焊点、D3、L1、C4、输出是否短路 |
| 6V 输入时 5V 只有 4.9V 左右 | 正常，压差接近直通 |
| 开发板反复重启 | 5V 是否稳、输入电流是否够、D2/排母接触、USB 与底板同时供电时先拔 USB 试 |
| 4S 模式下接收机没电 | 正常：接收机由电调 BEC 单独供电；确认 J17 的 +V 没有接板上 +BEC |
| 舵机抖动/发热 | J7/J8 的 +V 是否为 5V、地是否共地、5V 降压段电流够不够 |
| 遥控三通道没信号 | J17 有没有插（J9 没有地线，参考地靠 J17）、J9 三针顺序、GPIO 号 |
| 霍尔没信号 | 霍尔 +V 是否有电、10k 上拉、磁铁距离、GPIO 号、A3144 脚序 |
| U1 很烫 | 4S 输入压差大、5V 负载重（含舵机）；加散热片、减小负载或另配 5V BEC |
| 插上电调后电源异常 | 检查 J12 和 J16 是否同时接了；J16 的 +BEC 在 4S 模式下必须空着 |

## 9. 安全与限制

- 最高输入 **16.8V**（4S 满电），不要接 5S 或更高；4S 高压锂电（4.35V/节，
  满电 17.4V）虽然还在电容耐压余量内，但本板按 16.8V 标定，且没有过压保护，
  不建议长期使用。
- 板子不是充电器、不是 BMS，不要拿它给电池充电。
- 电池接入前先确认极性；虽然有 D1 防反接，但反复反接仍可能损伤端子/导线。
- 建议外接保险丝；避免金属物短路电池；不要在水/潮湿环境使用。
- 4S 模式下，接收机的电源必须另走 BEC（J17 的 +V 空着）；舵机可以接板载
  5V，但要按第 6 节核算 5V 段的电流和散热。板上 +BEC 只允许接霍尔、J15 的
  BEC 针、5V 降压段和你明确知道耐压足够的设备。
- 改线、插拔、换器件前先断开电池。

## 10. 版本说明

- 基线：v6 转接底板（96 × 98.5mm，2 层，全部直插）。
- v6 变更：开发板改为正面插装（J1 对右排 IO43 列、J2 对左排 3V3 列）；
  J7/J8 舵机 +V 固定为板载 5V；霍尔 J3~J6 脚序改成 A3144 的 +V/GND/OUT；
  遥控三通道合并成 J9 一个 3 针信号排针（J10/J11 取消），接收机电源/地
  仍走 J17；C4 升到 1000µF/16V。
- 与 v5 的接线差异：开发板换成正面插装；霍尔插头脚序变了；J9/J10/J11
  三个口变成一个 J9；舵机口仍是 S/+V/G，但 +V 从 BEC 变成 5V。v5 的接线
  不能直接照搬到 v6。
- v6 的 C1/R5/D3 已经按 4S 配置（C1 25V、R5 1.5k、D3 SB560），J12 可接
  4S（≤16.8V）；J17 的 +V 在 4S 模式下仍需空出，接收机由电调 BEC 供电。
